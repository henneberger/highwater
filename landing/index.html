from dataclasses import dataclass
from highwater import streaming

@streaming.process(key="session_id")
@dataclass
class SupportAgent:
    turns: int = 0

    @streaming.event
    async def respond(self, event):
        self.turns += 1
        answer = await streaming.call(
            "support_model", event.message,
            operation_id=event.id,
        )
        await streaming.wait_for(
            "approval", timeout="24h"
        )
        return {"answer": answer,
                "turn": self.turns}

Test method and boundaries

The stream test runs a compact deployment across three availability zones. Workers keep hot state on local NVMe while object storage holds the durable journal and content-addressed checkpoint blocks.

The workload mutates keyed state and writes a durable outgoing message for each event. Checkpoints upload changed blocks while retaining references to unchanged state. Recovery restores the newest checkpoint before replaying the remaining journal tail.

A separate reconciliation ledger checks per-key order and outgoing-message cardinality after worker termination and stateful upgrades. Recovery measurements cover the keys assigned to failed workers. Unaffected keys continue serving.

Inference tests report scheduling separately from model execution. Sandbox tests measure assignment through the start of user code across warm and cold paths.
