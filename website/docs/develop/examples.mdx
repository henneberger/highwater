---
title: Examples
description: Explore complete streaming applications.
---

Start `highwater server start-dev` and `highwater-worker examples.catalog`, then run each Python module against the normal ingestion API.

| Example | Run | Demonstrates |
| --- | --- | --- |
| Account balances | `python -m examples.durable_process` | ordered keyed state and event-time completeness |
| Durable order pipeline | `python -m examples.durable_order_pipeline` | keyed intake, durable stream edges, multi-stage activities, and retries |
| Clickstream recommendations | `python -m examples.clickstream_recommendation` | temporal enrichment, sessions, and recommendations |
| Sensor metrics | `python -m examples.iot_sensor_metrics` | watermarks, late data, filters, and sliding aggregates |
| Temporal join | `python -m examples.temporal_join` | fact-to-version as-of semantics and conditions |
| Embeddings | `python -m examples.batched_embeddings` | size-or-latency vectorized inference |

Read each example as a normal Python application. The definitions do not contain partition loops, checkpoint callbacks, or transport offsets.
