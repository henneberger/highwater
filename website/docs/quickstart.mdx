## Install

```bash
pip install highwater
```

The platform wheel contains the native streaming engine and Python SDK.

Create `app.py`:

```python
from dataclasses import dataclass
from highwater import streaming

@dataclass(frozen=True)
class Deposit:
    account_id: str
    amount: int

@streaming.process(key="account_id")
@dataclass
class Balance:
    total: int = 0

    @streaming.event
    async def apply(self, event: Deposit):
        self.total += event.amount
        return {"account_id": event.account_id, "balance": self.total}
```

## Start locally

```bash
highwater-server --state-dir .highwater/state --object-store-dir .highwater/objects
```

In another terminal:

```bash
highwater-worker app
```

The service owns durable state and ingestion. The worker discovers and executes the Processes in `app.py`.

## Publish an event

```python
from highwater import Client
from app import Deposit

client = Client()
balances = await client.get_process_handle("Balance")

await balances.send(
    Deposit(account_id="account-a", amount=5),
    event_id="deposit-1001",
)
```

Use a stable `event_id` whenever a producer may retry. The call returns after Highwater durably accepts the event, not after the Process finishes.

Read the materialized state:

```python
state = await balances.state("account-a")
print(state.total)
```

## Run against Highwater Cloud

```bash
export HIGHWATER_ADDRESS=https://api.highwater.cloud
export HIGHWATER_API_KEY=...
highwater example run account-balance
```

The address flag and environment variable work for every CLI command. Continue with [Processes](/develop/python/processes), [event ingestion](/develop/python/ingestion), and [deployment safety](/develop/python/upgrades).
