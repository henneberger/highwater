## Client

```python
from highwater import Client

client = Client()
orders = await client.get_process_handle("Order")
```

| Method | Result |
| --- | --- |
| `Client()` | client configured from the local or deployment environment |
| `await client.get_process_handle(name)` | handle for a deployed Process |
| `await client.deploy_process(definition, input=...)` | deploys a Process over an existing stream |
| `await client.start(definition)` | creates an input stream and deploys a Process |
| `await client.compare_builds(process_id, baseline=..., candidate=...)` | compares retained input and returns a reusable replay manifest |
| `await client.top_n(id, input=..., order_by=..., n=...)` | deploys a native retractable leaderboard |
| `await client.normalize(id, input=..., primary_key=...)` | normalizes keyed row changes |
| `await client.collection_rows(id, group=[...])` | reads indexed current collection rows |
| `await client.relational_operator(id)` | inspects collection mode, strategy, and retention |
| `client.view(operator_id)` | native operator result handle |
| `await client.snapshot_views(*operator_ids)` | saves a durable result cut |
| `await client.read_view_snapshot(snapshot_id)` | retrieves saved results |
| `await client.delete_view_snapshot(snapshot_id)` | releases saved results |

## ProcessHandle

| Method | Result |
| --- | --- |
| `send(event, *, event_id, event_time=None)` | durable admission receipt |
| `outcome(key, event_id)` | durable `PENDING`, `COMMITTED`, or `FAILED` execution outcome |
| `send_many(events)` | receipts in input order |
| `state(key)` | latest committed Process state |
| `drain()` | waits for admitted work to finish |
| `complete_through(event_time)` | declares progress through an event time |
| `finalize(key)` | closes a quiescent direct-ingress key to new events |
| `finality(key)` | reads its durable closure declaration |

## Decorators

| Decorator | Purpose |
| --- | --- |
| `@streaming.process(...)` | defines keying, state version, and event-time policy |
| `@streaming.event` | handles one eligible event |
| `@streaming.batch(...)` | handles a size-or-latency batch |
| `@streaming.migrate(from_version=N)` | migrates durable state |
| `@streaming.task` | defines retryable side-effecting work outside Process state transitions |

## Versioned reference streams

```python
catalog = streaming.versioned("catalog", key="product_id")

product = await catalog.get(
    view.product_id,
    as_of=context.event_time,
)
```

The Process deployment records the reference-stream dependency. An event becomes eligible after the reference stream's completeness frontier reaches the requested event time. The lookup returns the latest non-deleted value at or before `as_of`.

Versioned lookups are valid only inside a Process handler.

## Autoscaling

```python
from highwater import AutoscalingPolicy, WorkloadSample, recommend_replicas
```

`recommend_replicas(previous, current, current_replicas=..., partitions=...)` returns a `ScalingDecision`. The decision contains incoming and completed rates, the desired replica count, a reason, and one partition tuple for each active worker.

`assign_partitions(partitions, replicas)` assigns every executable partition once and keeps worker counts balanced.

## Replay comparison

`compare_process_builds(baseline, candidate, records, versioned_histories=...)` runs an offline comparison over `StreamRecord` values. `ReplayComparison.matches` is true when both builds produce identical state and output after every event. `ReplayComparison.differences` contains exact per-event changes.

`ReplayComparison.manifest` saves the exact captured inputs, reference histories, initial state, and build identities. Load it with `ReplayManifest.from_json` and reuse it with `compare_process_builds(..., manifest=manifest)`. It does not capture external responses or establish a coherent cut across live streams.
