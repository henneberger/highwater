title: Python API

## Client

```python
from highwater import Client

client = Client()
orders = client.process("Order")
```

| Method | Result |
| --- | --- |
| `Client()` | client configured from the local or deployment environment |
| `client.process(name)` | `ProcessHandle` |
| `client.close()` | closes client resources |

## ProcessHandle

| Method | Result |
| --- | --- |
| `send(event, *, event_id)` | durable admission receipt |
| `send_many(events)` | receipts in input order |
| `state(key)` | latest committed Process state |
| `output(key, *, after=None)` | asynchronous committed output stream |

## Decorators

| Decorator | Purpose |
| --- | --- |
| `@streaming.process(...)` | defines keying, state version, and event-time policy |
| `@streaming.event` | handles one eligible event |
| `@streaming.batch(...)` | handles a size-or-latency batch |
| `@streaming.migrate(from_version=N)` | migrates durable state |

## Runtime

| Call | Purpose |
| --- | --- |
| `streaming.key()` | current Process key |
| `streaming.event_id()` | stable input identity |
| `streaming.emit(event)` | emits transactional output |
| `streaming.send(target, event)` | sends transactionally to another Process |
| `streaming.wait_until(condition)` | suspends on a durable timer or event-time gate |

Runtime calls are valid only inside a Process handler.
