## Start locally

```bash
highwater server start-dev
```

Start application workers separately with `highwater-worker MODULE`.

## Connect

Every remote command accepts global connection options before or after the command:

| Option or environment variable | Meaning |
| --- | --- |
| `--address URL`, `HIGHWATER_ADDRESS` | service endpoint |
| `--api-key KEY`, `HIGHWATER_API_KEY` | bearer credential |

## Workflows

```bash
highwater workflow start --type TYPE [--id ID] [--arg JSON] [--wait]
highwater workflow describe --id ID
highwater workflow history --id ID
highwater workflow signal --id ID --name NAME [--arg JSON]
```

## Processes

```bash
highwater process describe --id ID
highwater process state --id ID --key KEY
highwater process send --id ID --key KEY --event JSON
highwater process complete --id ID --through EVENT_TIME
```

`process complete` advances an explicit event-time completeness boundary. It is not required for immediate Processes.

## Bundled examples

```bash
highwater example run account-balance
highwater example run order
```
